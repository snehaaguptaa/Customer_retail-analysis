# Customer_retail-analysis
This project is based on retail customer analysis where we analyzed insights using customer behaviour.
I have use Python and its libraries(i.e pandas and numpy) for manipulation and analysis of data , Postgresql for analysis of data , Advanced excel for data import, power bi for visualisation of data.
Adding to this i have also prepare documented report and presentation for the project.
